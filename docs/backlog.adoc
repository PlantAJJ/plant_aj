== Project Summary

PlantAJ is an AI-powered plant support application designed to help users identify plants, diagnose problems, and receive personalized plant care recommendations.

The project simulates a real Agile software development lifecycle using:

* GitHub Issues
* User Stories
* Milestones
* Pull Requests
* CI/CD checks
* Branching strategies
* Agile sprint planning
* Project documentation

== Product Vision

Build an intelligent assistant for plant owners that provides:

* Plant identification
* Care recommendations
* Disease/problem detection
* Watering and sunlight guidance
* AI-powered support and suggestions

== Pull Request Template

=== PR Title Format

`[TYPE] Short Description`

Examples:

* `[FEATURE] Add AI plant identification endpoint`
* `[FIX] Resolve login validation issue`
* `[DOCS] Update setup instructions`

=== Pull Request Description Template

==== Summary

Brief description of the implemented changes.

==== Related Issue

[source,text]
----
Closes #ISSUE_NUMBER
----

==== Changes Made

* Added:
* Updated:
* Fixed:

==== Testing

* [ ] Unit tests passed
* [ ] Manual testing completed
* [ ] CI pipeline successful

==== Screenshots (if applicable)

Attach screenshots or UI previews.

==== Checklist

* [ ] Code follows project standards
* [ ] Documentation updated
* [ ] No console errors
* [ ] PR reviewed before submission

== Definition of Done (DoD)

A task is considered complete when:

* Code is implemented
* Acceptance criteria are met
* Tests pass successfully
* PR is reviewed and approved
* CI checks succeed
* Documentation is updated
* Changes are merged into the main branch
